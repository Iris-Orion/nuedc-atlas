理论与分析

01

非线性对象建模与工作点线性化

传递函数状态空间工作点线性化右半平面极点能控能观

先写牛顿方程，再在平衡点上做一阶泰勒展开，才能得到能拿去设计的线性模型。本赛道的对象（球杆、磁悬浮、倒立摆）本质都是非线性的，但比赛用的是小范围镇定，所以把非线性方程在工作点 (x0, u0) 处线性化成 ΔẊ = AΔx + BΔu 完全够用。关键是搞清楚线性化以后极点落在哪里——落在原点是"欠稳定"（可镇定但难做），落在右半平面是"开环不稳定"（不闭环就一定发散）。

球杆系统（ball-and-beam）。实心钢球在斜角 θ 的杆上滚动，滚动无滑移时转动惯量 J = 2/5·mR2，沿杆方向的动力学是 (J/R2 + m)ẍ = mg·sinθ − mx·θ̇2。忽略离心项、取 sinθ ≈ θ，得到：

ẍ = (5/7)·g·θ   ⇒   Gb(s) = X(s)/Θ(s) = 5g / (7s2) ≈ 7.0 / s2
x 球在杆上的位置 (m)，θ 杆倾角 (rad)，g = 9.8 m/s2，5/7 来自实心球的滚动惯量修正（空心球是 3/5，滑块是 1）

两个极点都在原点，是纯双积分：幅频 −40 dB/dec、相位恒 −180°，纯比例反馈相位裕度为 0，一定等幅振荡。所以球杆题必须引入微分（PD）或超前校正，把相位在穿越频率处抬回 40°–60°。再串上驱动杆的舵机/电机环 Θ(s)/Θcmd(s) ≈ 1/(τss+1)，τs 一般 30–80 ms，这一节滞后就是外环带宽的天花板。

磁悬浮。电磁铁吸力近似 F = C·i2/x2，运动方程 mẍ = mg − C·i2/x2。平衡点满足 C·i02/x02 = mg，对 x、i 各求一次偏导：

mΔẍ = (2mg/x0)·Δx − (2mg/i0)·Δi
Gm(s) = ΔX(s)/ΔI(s) = − (2g/i0) / (s2 − 2g/x0)
x0 平衡气隙，i0 平衡电流；Kx = 2mg/x0 是"负刚度"，Ki = 2mg/i0 是电流增益

为什么磁悬浮开环不稳定：分母 s2 − 2g/x0 的根是 s = ±√(2g/x0)，其中 +√(2g/x0) 是右半平面实极点。物理含义就是那个负刚度项 +KxΔx：球稍微靠近磁铁一点，气隙变小、吸力变大，于是更靠近——正反馈。取 x0 = 5 mm，p = √(2×9.8/0.005) ≈ 62.6 rad/s ≈ 10 Hz，对应发散时间常数 1/p ≈ 16 ms。由 Bode 灵敏度积分的工程结论，闭环穿越频率必须取到不稳定极点的 5–10 倍，即 ωc ≥ 300–600 rad/s（50–100 Hz），采样率相应 ≥ 1–2 kHz。这条不等式直接决定了你不能用 20 ms 才出一个数的传感器去悬浮。

能控能观。写成状态空间后查 rank[B AB … An−1B] = n 与 rank[C; CA; …; CAn−1] = n。球杆取 x = [位置, 速度, 杆角, 杆角速度]T 时满秩；但如果只测球位不测杆角，用观测器估杆角在噪声下会很吃力，比赛里更稳的做法是杆角直接装编码器测。

电赛怎么考

2024 赛区赛/省联赛 F 题「磁悬浮实验装置」：整题的门槛就在上面那个右半平面极点——只要没先做线性化、没估出 x0 和 √(2g/x0)，就无法判断自己的位置采样率和执行带宽够不够，结果是"能吸住、不能悬住"，基本要求的稳定悬浮时长与气隙保持这一档直接丢分。2026 赛区赛/省联赛 H 题「车载平衡滚球运动控制系统」：钢球定位误差要求 ≤ 1 cm、整圈时间 ≤ 30 s，这两条一起把双积分模型的带宽逼到墙角——1 cm 精度要求低频增益足够，30 s 整圈要求外环跟得动，没有 5g/7s2 这个模型就只能靠盲试参数。

常见坑

（1）直接拿"电压 → 位置"当被控对象。电磁铁本身是 I(s)/U(s) = 1/(Ls+R)，L 10–100 mH、R 5–20 Ω，L/R 时间常数 2–10 ms，和 16 ms 的发散时间常数在同一量级，会把相位吃光；正确做法是先做电流内环把它压成近似 1（见 02 条）。（2）线性化系数用手册值而不实测。C 受铁芯饱和、漏磁影响很大，务必用"给定电流—刚好悬浮"的实测点反推 Ki = 2mg/i0。（3）球杆忘了 5/7 系数，用 g 代替 5g/7，增益差 40%，整定出来的 Kd 系统性偏小。

02

PID 整定、串级与超前校正

Ziegler-Nichols相位裕度串级双闭环带宽比超前校正

整定不是拧旋钮碰运气，Z-N 给你一个能跑的起点，频域法告诉你还能往上推多少。先把 PID 写成标准式 u = Kp[e + (1/Ti)∫e dt + Td·de/dt]，这样 Z-N 表才对得上。

Z-N 临界比例度法（闭环）。去掉 I、D，只留 P，把 Kp 从小往上加到系统刚好等幅振荡，记下临界增益 Ku 与振荡周期 Tu（秒）：

控制器KpTiTd说明
P0.5 Ku——有稳态误差
PI0.45 KuTu/1.2—超调 ~25%
PID（经典）0.6 Ku0.5 Tu0.125 Tu超调 ~25%，最常用起点
PID（小超调）0.33 Ku0.5 Tu0.33 Tu演示打分更好看
PID（无超调）0.2 Ku0.5 Tu0.33 Tu响应慢，适合定位

Z-N 阶跃响应法（开环）。对开环稳定对象加阶跃，在响应曲线拐点作切线，量出滞后 L（切线与时间轴交点）和时间常数 T（切线升到稳态值所需时间），记 R = K/T·（单位阶跃下的最大斜率）。经典表：P 取 Kp = T/L；PI 取 Kp = 0.9T/L、Ti = 3.33L；PID 取 Kp = 1.2T/L、Ti = 2L、Td = 0.5L。注意这一支不适用于磁悬浮/倒立摆——开环发散，画不出阶跃曲线，只能用闭环法或直接频域设计。

频域法：用相位裕度反推增益。目标是选一个穿越频率 ωc，让开环在那里幅值为 1、相位比 −180° 高出 γ（相位裕度，工程上取 40°–60°，本赛道推荐 45°）。步骤：① 画出 G(jω) 的 Bode 图（PC 端用 python-control 三行搞定）；② 找到满足 ∠G(jω) = −180° + γ 的那个 ω，记为 ωc；③ 令

K = 1 / |G(jωc)|   ;   γ = 180° + ∠[K·G(jωc)]
γ 相位裕度；若加了 PID，∠ 里要算上 PID 自身的相位 ∠C(jω) = arctan(ω Td) − arctan(1/(ω Ti))

如果在期望的 ωc 处相位不够，就补超前校正 C(s) = (1 + aTs)/(1 + Ts)，a > 1，它在 ωm = 1/(T√a) 处给出最大超前角 φm = arcsin[(a−1)/(a+1)]，反解 a = (1 + sinφm)/(1 − sinφm)。补 45° 需 a ≈ 5.8，补 55° 需 a ≈ 10，单级超过 60° 就不实用（高频增益放大 a 倍，噪声爆炸），要补 70°–80° 请用两级串联。磁悬浮位置外环几乎一定要一级超前，因为对象在 ωc 处相位已经接近 −180°。

串级（双闭环）与带宽比。结构是外环输出当内环给定：位置环 → 速度/角度环 → 电流环。内环存在的意义是把一个带滞后、带非线性、带扰动的执行通道，在外环看来"打包成一个近似 1 的环节"。要做到这一点，内环带宽必须是外环的 3–10 倍，工程经验值取 5 倍。原因可以直接算：内环闭环近似一阶惯性 1/(s/ωbi + 1)，它在外环穿越频率 ωco 处贡献的附加相位滞后是 −arctan(ωco/ωbi)：

ωbi/ωco内环给外环的额外相位滞后结论
2×−26.6°吃掉一半裕度，外环调不动
3×−18.4°下限，勉强可用
5×−11.3°推荐值，代价可接受
10×−5.7°理想，但内环往往做不到这么快

典型数字：电流环 1–2 kHz（取 PWM 频率的 1/10 左右）、速度/角度环 100–200 Hz、位置环 20–50 Hz。球杆题因为外环还挂着摄像头，位置外环通常只能做到 1–3 Hz，那么杆角内环至少要 10 Hz 以上才算合格。调参顺序永远是从内往外，内环没锁死之前调外环等于在流沙上盖楼。

电赛怎么考

2017 国赛 B 题「滚球控制系统」：把球移到指定区域并稳定停住若干秒，这一档考的就是双积分对象上的 PD/超前——只加 PI 的队伍必然来回穿越目标点不收敛。2024 赛区赛/省联赛 F 题「磁悬浮实验装置」：电流内环 + 位置外环是标配，位置外环没有超前校正就没有相位裕度，表现为一放手就撞铁芯或者高频"嗡嗡"抖。2026 赛区赛/省联赛 H 题「车载平衡滚球运动控制系统」：摄像头外环（1–3 Hz）与摆杆角内环（10–30 Hz）刚好是 5–10 倍关系，误差 ≤ 1 cm 这条指标就落在外环低频增益上。

常见坑

（1）Z-N 的 Ku 要在去掉限幅、去掉滤波的条件下测，否则测到的是非线性极限环的增益，套表出来偏小一倍。（2）微分项直接对误差求导会被给定阶跃打出尖峰，改用"微分先行"：D 只对测量值 y 求导且取负号，并串一个 N = 8–20 的一阶滤波 Tds/(1 + Tds/N)。（3）Z-N 出来的参数超调 20%–25%，是起点不是终点，演示前按"小超调"那行往下压。（4）内外环用同一个采样周期是允许的，但外环的执行频率要降下来（如内环 1 kHz、外环 50 Hz 分频执行），否则外环在被自己的量化噪声激励。

03

LQR、状态观测器与抗积分饱和

LQRBryson 规则卡尔曼滤波观测器极点anti-windup

当对象有 4 个以上状态、手调 PID 开始互相打架时，就该换成"全状态反馈 + 观测器"。LQR 求的是让二次型代价最小的反馈阵 K，u = −Kx：

J = ∫0∞ (xTQx + uTRu) dt   ,   K = R−1BTP
ATP + PA − PBR−1BTP + Q = 0（代数 Riccati 方程）
Q ≥ 0 惩罚状态偏差，R > 0 惩罚控制量；R 越大控制越"温柔"，带宽越低

权重怎么选：Bryson 规则。不要凭感觉填数，按"各量允许的最大偏差"归一化：Qii = 1/xi,max2，Rjj = 1/uj,max2。举例球杆：球位允许偏 0.01 m、球速允许 0.1 m/s、杆角允许 0.1 rad、杆角速度允许 1 rad/s，则 Q = diag(10000, 100, 100, 1)；控制量是杆角指令，上限 0.2 rad，R = 25。然后只留一个标量旋钮 ρ，用 Q 与 ρR 扫描：ρ 减小 10 倍，闭环带宽大约提高 √10 ≈ 3 倍。在 PC 上用 python-control 的 lqr(A,B,Q,R) 反复扫，把闭环极点和阶跃响应画出来再下板子，比在实物上试快一个数量级。

观测器。球速、杆角速度这类状态一般不直接测（差分会放大噪声），用 Luenberger 观测器 x̂̇ = Ax̂ + Bu + L(y − Cx̂)。观测器极点取控制器极点的 3–5 倍快：太慢则估计跟不上，太快则把测量噪声全放进状态里。有随机噪声统计时换卡尔曼：L = PCTRv−1，Qw 描述过程噪声（模型不准的程度），Rv 描述测量噪声（传感器方差，用静止时采 1000 点算方差直接填）。工程上 Qw/Rv 的比值就是"信模型还是信传感器"的旋钮。

抗积分饱和（anti-windup）。舵机只能转 ±60°、电流只能给 3 A，一旦执行器饱和，积分项还在累加，等误差反号时要花很久才"放完"，表现为大幅超调 + 长时间反向不动。三种可落地写法：

  • 条件积分（clamping）：if (u_raw != u_sat) I += Ki*e*Ts; 饱和时干脆停止积分。三行代码，最常用。
  • 反算法（back-calculation）：I += Ki*e*Ts + Kt*(u_sat - u_raw)*Ts; 取 Kt ≈ 1/Kp（或 1/√(TiTd)），退饱和更平滑。
  • 积分限幅：单独把 I 项夹在 ±(0.3–0.5)·umax，防止 I 独吞全部输出余量。
  • 再配一条：给定端加斜坡限速，让参考本身不要一次跳到执行器给不出的地方，从源头减少饱和。
电赛怎么考

2026 赛区赛/省联赛 H 题「车载平衡滚球运动控制系统」：小车 + 摆杆 + 球是多状态耦合，钢球误差 ≤ 1 cm 而整圈 ≤ 30 s 意味着"又要准又要快"，全状态反馈（球位、球速、杆角、杆角速度）配 LQR 比四个串起来的 PID 更容易同时满足；球速必须靠观测器估，因为摄像头直接差分出的速度噪声能有几十 cm/s。2023 国赛 I 题「气垫悬浮车」：气垫车在低摩擦面上惯性大、阻尼几乎为零，速度指令一旦饱和，普通 PI 的积分退饱和过程会让车冲过停止线，抗饱和处理直接决定定点停车这一档能不能拿。

常见坑

（1）LQR 算出来的 K 是连续域的，直接放进 1 kHz 定时器还行，放进 50 Hz 循环就要用离散 Riccati（dlqr）重算，否则实测比仿真差很多。（2）观测器里的 B 矩阵必须喂实际发出去的 u（限幅后），喂限幅前的 u 会让估计发散——这是最隐蔽的一个 bug。（3）卡尔曼的 Rv 填得太小等于告诉滤波器"传感器绝对准"，结果输出跟原始噪声一模一样，滤了等于没滤。（4）状态量单位不统一（一半用度、一半用弧度）会让 Q 的相对权重差 57 倍，务必全程 SI 单位。

04

采样周期、纯延迟与 Smith 预估

采样定理相位滞后ωτ延迟裕度Smith 预估器

纯延迟不改变幅值，只吃相位，而相位裕度就是稳定性本身——这是本赛道最贵的一条常识。延迟环节的频率特性是 e−jωτ，模恒为 1，相角为：

∠e−jωτ = −ω·τ (弧度) = −57.3 × ω × τ (度)
ω 角频率 (rad/s)，τ 纯延迟 (s)。注意 ω = 2πf，f 是 Hz

用视觉延迟算一个实例。摄像头测位的端到端延迟 τ 典型 30–60 ms（曝光 + 传输 + blob 检测 + 串口 ≈ 1.5–2 帧）。取 τ = 45 ms：

ω (rad/s)f (Hz)相位滞后 ωτ (rad)折成度
50.800.225−12.9°
101.590.45−25.8°
203.180.90−51.6°
355.571.575−90.2°

结论一目了然：这个 45 ms 延迟在 3.2 Hz 处就吃掉 51.6° 相位。而球杆对象本身（双积分）已经是 −180°，PD 校正最多抬回 +80°，剩下的裕度全给延迟消化——所以摄像头闭环的穿越频率现实上限就在 1.5–3 Hz。反过来用：给延迟留 30° 的相位预算，则 ωc ≤ (30/57.3)/τ = 0.52/τ。τ = 30 ms → ωc ≤ 17.5 rad/s (2.8 Hz)；τ = 60 ms → ωc ≤ 8.7 rad/s (1.4 Hz)。延迟翻倍，可用带宽减半，这是硬约束，加大 Kp 只会更快发散。

还有个对称的量叫延迟裕度：在已知相位裕度 γ（弧度）和穿越频率 ωc 下，系统还能容忍的额外延迟是 τmax = γ/ωc。γ = 45° = 0.785 rad、ωc = 10 rad/s，则 τmax = 78 ms——这就是你的"延迟预算表"，任何新加的滤波器都要从这里扣。

采样周期怎么选。零阶保持等效于额外的 Ts/2 纯延迟，所以采样本身也在吃相位。经验规则：采样频率 fs ≥ 10–20 倍闭环带宽（不是 2 倍！奈奎斯特是重构信号的下限，不是控制的下限），或者说 Ts ≤ (1/20 ~ 1/10) 的闭环上升时间。对应到本赛道：磁悬浮 1–2 kHz（不稳定极点 10 Hz，带宽要 50–100 Hz）；电机电流环 10–20 kHz；杆角内环 200–1000 Hz；摄像头外环受硬件限制 60–120 Hz。另外要列一张总延迟清单：传感器本身延迟 + 数字滤波群延迟（N 点滑动平均是 (N−1)Ts/2）+ 采样保持 Ts/2 + 计算耗时 + 执行器上升时间，把它们加起来才是代进 ωτ 的那个 τ。

Smith 预估器。当延迟占主导（τ 与对象时间常数可比）时，用模型把延迟"移出"反馈回路：控制器输出同时喂给真实对象和内部模型 G0(s)（无延迟部分）与 G0(s)e−sτm，反馈信号取 y − [G0e−sτm]u + [G0]u，理想匹配下等效开环变成 C(s)G0(s)，延迟消失，可以按无延迟对象整定。代价是对模型极其敏感：τ 估偏 20% 就可能不稳，且不能用于开环不稳定对象（内部模型会自己发散，磁悬浮直接排除）。所以视觉伺服里更常用它的"状态预测"变体：用卡尔曼/等速模型把状态外推 N = round(τ/Ts) 拍，x̂(k+N) = ANx̂(k)（见第 10 条），鲁棒性好得多，也好写。

常见坑

（1）只算摄像头曝光时间就当成延迟，漏掉图像传输和串口。实测方法：让 LED 在被摄场景里闪一下，同时用示波器看 MCU 拿到坐标跳变的时刻，两者时间差就是真 τ，一次实验解决所有争论。（2）为了"降噪"在回路里串了 8 点滑动平均，fs = 100 Hz 时它带来 35 ms 群延迟，比传感器本身还多。滤波器一定要算群延迟并计入预算。（3）主循环用 delay() 凑周期，实际执行抖动几十毫秒，导致微分项算出来忽大忽小；必须用定时器中断固定 Ts，并且微分/积分里用实测的 dt。（4）Smith 预估器套在磁悬浮上，一上电就飞——记住它只适用于开环稳定对象。

舵机的关键数字。标准 PWM 周期 20 ms（50 Hz），脉宽 1000–2000 μs 对应 ±60°（或 500–2500 μs 对应 ±90°）。50 Hz 更新率意味着零阶保持等效延迟 10 ms，加上舵机内部环路，等效一阶惯性 τs ≈ 30–80 ms。用支持 333 Hz 的数字舵机能把这一节砍到 1/6。空载速度 0.15 s/60° 折算约 400°/s，这是速率限幅的实际值，超过它舵机就进入非线性区。分辨率对球杆题的意义：0.5° = 0.0087 rad，代入 ẍ = 5g/7·θ 得球的加速度量化台阶 0.061 m/s2——这就是稳态抖动的下界，1 cm 精度要求下必须选 0.1° 级的执行器。

位置与速度传感方案

编码器 M/T 法IMU 互补滤波光电测距摄像头测位噪声与延迟

选传感器要同时看三个数：分辨率、噪声方差、延迟——学生通常只看第一个。

增量编码器与测速。N 线编码器四倍频后每圈 4N 个脉冲。三种测速法要按转速分区用：

  • M 法（测频）：固定时间 T 内数脉冲数 M1，n = 60·M1/(4N·T) rpm。速度分辨率 Δn = 60/(4N·T)。取 N = 500、T = 10 ms，Δn = 3 rpm。高速准，低速时 M1 只有个位数，量化误差巨大。
  • T 法（测周）：测相邻两脉冲间的高频计数值 M2，n = 60·fc/(4N·M2)。低速准，高速时 M2 太小失去精度。
  • M/T 法：在约 T 时间内同时数脉冲数和精确计时，全速域可用，是工程首选。

不做这个区分，就会出现"低速时速度环疯狂抖、高速时正常"的经典现象。另外编码器速度务必配一阶低通（截止取速度环带宽的 2–3 倍），但要把群延迟计入第 04 条的预算。

IMU。陀螺仪积分得到角度，短期准但有零偏漂移（几度/分钟）；加速度计算倾角，长期准但被机体加速度污染。互补滤波把两者拼起来：

θk = α·(θk−1 + ωgyro·Δt) + (1 − α)·θacc  ,  α = τ/(τ + Δt)
τ 是交接时间常数，典型 0.5–1 s；Δt = 5 ms、τ = 0.5 s 时 α = 0.990

上电必须静置 1–2 s 采 500–1000 点做陀螺零偏标定，这一步省掉的话角度会以肉眼可见的速度漂走。车载场景（如小车带着摆杆走）加速度计被小车加速度污染，此时更该相信陀螺、把 τ 加大到 2 s 以上，或者干脆用第 12 条的前馈把已知加速度扣掉。

磁悬浮的位置检测。红外对管（发射管 + 接收管，被小球遮挡的面积调制光强）线性区只有几毫米但分辨率能到 10 μm、带宽几 kHz，是首选；电感式/电涡流传感器更稳定但要自己做振荡电路。关键点：这个通道的带宽必须 ≥ 1 kHz，因为要支撑 50–100 Hz 的闭环带宽。用 20 Hz 更新的激光模块（如 VL53L0X，单次 20–33 ms）做磁悬浮位置反馈是必失败的组合。

摄像头测位。OpenMV 类模块在 QQVGA/QVGA 下 blob 检测可以跑到 60–120 fps，端到端延迟 30–60 ms。像素精度换算：视场 40 cm 宽、横向 320 像素，则 1 像素 = 1.25 mm，做到 1 cm 精度需要 ±8 像素的稳定性，因此光照与阈值稳定性比摄像头分辨率更重要——固定曝光、关掉自动白平衡、给球用高饱和度颜色、必要时加环形补光。丢帧要有兜底策略（见第 11 条）。

常见坑

07

H 桥功率接口与储能放电

死区时间电流限幅母线泵升制动电阻电容储能

H 桥是把控制量变成物理量的最后一米，它的非线性会直接伪装成"控制器调不好"。

死区时间。同一桥臂上下管不能同时导通，驱动必须插入死区 td，MOS 管典型 0.5–2 μs、IGBT 1–3 μs。代价是死区失真：输出电压相对指令有一个与电流方向有关的偏差 ΔU = (td/TPWM)·Ubus·sgn(i)。取 td = 1 μs、fPWM = 20 kHz（T = 50 μs）、Ubus = 24 V，ΔU = 0.48 V，相当于在零点附近有一个 ±0.48 V 的死区。表现出来就是"小占空比时电机不转，稍微加大就突然跳起来"——很多队误判为摩擦，其实是死区。补偿方法：根据电流符号在占空比上加回 ±td/TPWM，或者用带自适应死区的集成驱动芯片。

PWM 频率选择。取 16–25 kHz（避开听觉范围但开关损耗可控），电流环采样与 PWM 同步（在计数器上溢/下溢中断里采样，避开开关噪声）。电流环带宽取 PWM 频率的 1/10 左右，即 1.6–2.5 kHz。

电流限幅要分两级。软件限幅（在电流环给定处夹住，如 ±3 A）负责正常工作；硬件限幅（比较器 + 驱动芯片的 nFAULT / 逐周期限流）负责堵转和短路，阈值取软件限幅的 1.5–2 倍。只做软件限幅的后果是：程序跑飞的一瞬间 MOS 就冒烟了。

能量回馈与泵升。电机减速时是发电机，能量灌回母线。如果电源是不能吸收电流的（例如二极管隔离的开关电源或电池充电保护生效），母线电容电压会被抬高——泵升。判据很简单：监测 Ubus，超过额定值 1.15 倍就打开泄放。制动电阻取值 Rb ≈ Ubus,max/Imax（24 V / 5 A ≈ 5 Ω），功率按占空比估（脉冲工作时 5–20 W 够用），串一个 MOS 由 MCU 或比较器控制。母线电容也要够大：C ≥ 2Ek/(Umax2 − Unom2)，其中 Ek 是要吸收的动能。

曲射炮的储能与可控放电是完全另一套。能量 E = ½CU2，例如 C = 4700 μF、U = 300 V，E = 211 J。放电回路的峰值电流 Ipk ≈ U√(C/L)，线圈 L = 200 μH 时 Ipk ≈ 1.45 kA，脉宽 π√(LC) ≈ 3 ms。工程要点：

  • 开关用可控硅（SCR）最简单——门极触发后自然过零关断，正好匹配单脉冲；要多级加速则用 IGBT 主动关断。
  • 必须并续流二极管吸收线圈反电动势，否则开关瞬间反压击穿器件。
  • 充电电压要闭环控到设定值再触发（用分压 + ADC，充到目标就停充），否则每次残压不同、射程离散。
  • 高压部分与控制部分光耦隔离，且必须有泄放电阻（100 kΩ 级）在断电后把电容放掉。
电赛怎么考

2019 国赛 H 题 / J 题「模拟电磁曲射炮」：射程精度与重复性这一档，本质考的是"充电电压闭环 + 触发时序一致性"，即上面那套储能放电电路；很多队射程能到但每发落点散布大，扣分点就在残压和触发抖动。2023 国赛 I 题「气垫悬浮车」：气垫风机与驱动电机同时工作，母线电流冲击大，电流限幅与母线去耦没做好会导致 MCU 复位、车中途失控。2026 赛区赛/省联赛 H 题「车载平衡滚球运动控制系统」：整圈 ≤ 30 s 要求小车频繁加减速，减速段的能量回馈会抬高母线，泵升不处理会触发驱动过压保护而突然失力，直接把球甩掉。

常见坑

（1）自举电容供电的上管在占空比接近 100% 时因为下管一直不导通而无法充电，导致上管掉驱动。留 2%–5% 的最小下管导通时间，或用隔离电源/电荷泵。（2）功率地与信号地一点接地没做，ADC 采样被开关噪声打得跳几十个 LSB，误以为传感器坏了。（3）电流采样运放的带宽不够（< 100 kHz），采到的是被平滑过的假电流，电流环整定必然失败。（4）高压电容测试前不放电，测量时短路打火——每次上手前先用泄放电阻确认电压 < 30 V。

两轴云台的机械误差链

俯仰/偏航齿隙回差极限环角度分辨率静摩擦补偿

云台题的分差往往不在算法，而在"1 个角度单位落到靶面上是多少毫米"。先做这道换算题：靶距 L、要求落点误差 e，则允许的角度误差为

Δθ ≈ e / L (弧度) = 57.3 × e / L (度)
L 云台到靶面的距离，e 靶面上允许的偏差；小角度近似，L ≫ e 时成立

取 L = 3 m、e = 1 cm，Δθ = 0.0033 rad = 0.19°。这意味着：模拟舵机 0.5° 的死区（≈ 2.6 cm@3 m）物理上就够不着，必须换 0.1° 级的数字舵机、或者电机 + 减速 + 磁编码器方案。这是选型阶段就该算清楚的，不是调参能补的。

机械间隙（backlash）与回差。齿轮/皮带的空程 δ 会让"指令反向的头 δ 度"没有任何输出，构成一个死区非线性。它和积分器组合起来一定产生极限环：误差累积 → 积分推动 → 穿过间隙 → 冲过头 → 反向 → 又要穿间隙……表现为激光点在目标附近以 0.5–2 Hz 小幅左右横跳。三条对策：

  • 机械优先：皮带加预紧、齿轮做双片消隙、或者干脆直驱（无刷云台把电机直接装在轴上，间隙为零）。这是最有效的一条。
  • 单向趋近：定位时永远从同一侧接近目标（先过冲 0.5° 再回，或者反过来），把回差变成固定偏置，标定一次减掉。
  • 控制律：在接近目标时切换到纯 P + 死区（|e| < 阈值就不动），关掉积分；或用 back-calculation 抗饱和 + 输出死区补偿（输出非零时加上 ±ufriction）。

静摩擦与 Stribeck 效应。静摩擦大于动摩擦，导致"给一点力不动、加大一点突然窜出去"。补偿写法很简单：u += (fabs(e) > e_dead) ? sign(e)*u_c : 0; 其中 uc 用实验测——缓慢增大开环输出直到刚好起动，取那个值的 80%。这一步能把小误差下的响应速度提高一个档次。

几何解析优于纯图像闭环。当目标位置可以由几何关系算出来时（例如小车已知位姿、靶面已知尺寸），直接解算"小车位姿 → 靶面坐标 → 云台两轴角度"的映射再前馈过去，比让图像误差慢慢闭环快得多——闭环只用来消掉标定残差。两轴云台的正解（偏航 φ、俯仰 ψ，目标在云台坐标系下为 (X, Y, Z)）：φ = atan2(Y, X)，ψ = atan2(Z, √(X2+Y2)）。标定要做的是找出云台原点相对小车/靶面的平移与初始零位，用 4–6 个已知点做最小二乘拟合即可。

两轴耦合：俯仰轴通常装在偏航轴上，偏航转动会带动俯仰轴的姿态，且负载重心变化会改变俯仰所需力矩。低速下可以忽略，追踪快速目标时要么做重力/惯性前馈，要么把俯仰环带宽做高一倍让它自己吃掉。

电赛怎么考

2025 国赛 E 题「简易自行瞄准装置」：小车行进 + 二维云台激光瞄准，瞄准精度这一档几乎全部由上面的 Δθ = e/L 换算和云台标定决定；用纯图像闭环去搜索目标的队伍会因为搜索时间超时而丢分，而用"位姿 → 靶面坐标 → 两轴角度"几何解析 + 小幅闭环修正的队伍又快又准。2023 国赛 E 题「运动目标控制与自动追踪系统」：绿色光斑追红色光斑，容差在厘米量级，云台的机械回差直接表现为光点抖动收不住；这道题还要求跟上匀速运动的目标，所以除了消隙还必须加速度/速度前馈（见第 10 条）。

常见坑

（1）云台重心没配平，俯仰轴在不同角度需要的力矩差很多，一套 PID 在水平位置好用、抬到 40° 就抖。先做机械配平，再谈控制。（2）激光笔装在云台上但光轴与转轴不共面，产生随角度变化的系统偏差，标定时会发现"近处准远处不准"。装配时让激光出射点尽量落在两轴交点附近。（3）用 atan 而不是 atan2，象限判断错误导致云台在某些方位突然转 180°。（4）舵机 PWM 用软件模拟，主循环一忙脉宽就抖 20–50 μs（≈ 2–5°），云台看起来"随机抽搐"；一定用硬件定时器输出。

由内到外的调参流程

开环辨识FOPDT采样周期内环先行阶跃验证

调参有唯一正确的顺序，跳步的代价是几十小时的无效试错。五步，每步都有明确的通过判据：

第一步：开环辨识。断开所有反馈，直接给执行器一个阶跃（比如给舵机 +5° 或给电机 30% 占空比），用日志记录输出响应。开环稳定的对象（电机速度、小车速度、云台角度）拟合成一阶惯性 + 纯延迟（FOPDT）：G(s) = K·e−Ls/(Ts + 1)。K 是稳态增益（输出变化/输入变化），T 是升到 63.2% 的时间，L 是响应开始前的死时间。三个数一记，Z-N 阶跃法的参数当场就能算出来（第 02 条）。开环不稳定的对象（磁悬浮、球杆）不能这么做，改用手扶法：用手托住小球给一个已知电流，测出刚好平衡的 i0 和 x0，反推 Ki、Kx。

第二步：定采样周期。由第一步的 T 和目标带宽决定：Ts ≤ T/10，同时 fs ≥ 10–20 倍闭环带宽。定下来之后写死在定时器里，之后不再改——改采样周期等于改了所有离散 PID 系数，前面的整定全部作废。同时把总延迟清单列出来（第 04 条）。

第三步：调最内环（电流环 / 速度环）。判据是给方波给定，实际值能在 2–3 个时间常数内跟上、超调 < 10%、无稳态误差。电流环一般用 PI（不加 D），按 Kp = L·ωci、Ki = R·ωci 的零极点对消法直接算，ωci 取 2π×(1–2 kHz)。速度环同样 PI。这一环没调好之前，绝不动外环。

第四步：调中间环（杆角 / 云台角）。先纯 P 加到临界振荡测 Ku、Tu，套 Z-N 表拿起点，再按"小超调"那行往下压。判据：阶跃指令 10°，上升时间 < 100 ms，超调 < 15%，静差 < 0.5°。

第五步：调外环（位置）。此时把内环当成 1/(s/ωbi + 1)，外环带宽定在 ωbi/5（第 02 条）。球杆这类双积分对象先用 PD（Kd 是主角），确认能停住之后再慢慢加 I 消静差，I 一定要配抗饱和。判据：给一个位置阶跃，无持续振荡、稳态误差在指标之内。

验收要画两张图：实测阶跃响应（标出上升时间、超调、调节时间、稳态误差），以及开环 Bode 或至少用正弦扫频测出的幅值/相位（标出 ωc 和相位裕度 γ）。扫频不需要仪器：程序里生成 0.2–20 Hz 的 chirp 给定，记录给定与输出，PC 端用 python-control / numpy 做 FFT 求比值即可。有这两张图，报告分和答辩都稳。

视觉延迟的预测补偿

等速模型卡尔曼预测N 拍外推时间戳对齐丢帧处理

摄像头给你的是 40 ms 前的世界，控制器却要对现在做决定，中间这段必须靠模型补上。第 04 条已经算过：τ = 45 ms 在 3 Hz 处吃掉 51.6° 相位。而补偿的思路不是"消除延迟"，是"把状态外推到现在（甚至未来一点）"。

最简单可用的版本：等速外推。拿到第 k 帧的位置 yk，先差分估速度，再外推 τ：

v̂k = (yk − yk−1) / Tcam   ;   ŷnow = yk + v̂k·τ
Tcam 帧间隔，τ 端到端延迟。τ = 45 ms、球速 20 cm/s 时补偿量 9 mm——正好是 1 cm 指标的量级

它的问题是差分把噪声放大：像素噪声 1 mm、Tcam = 16.7 ms，速度噪声约 85 mm/s，乘 τ 后引入 3.8 mm 抖动。所以裸差分要配一阶低通（截止 5–10 Hz），或者直接上卡尔曼。

推荐版本：等速卡尔曼 + N 拍外推。状态 x = [位置, 速度]T，模型

A = [1, Ts; 0, 1] , C = [1, 0] , Qw = q·[Ts4/4, Ts3/2; Ts3/2, Ts2] , Rv = σpix2
q 是加速度过程噪声功率密度（球杆上取球可能的最大加速度平方量级，如 (0.5 m/s2)2）；σpix 由静止时采 1000 帧算标准差实测

控制器用的量是 x̂(k+N) = AN·x̂(k)，其中 N = round(τ / Ts)。代码层面只有两处改动：预测步照常每个控制周期跑（Ts = 控制周期，比帧率快），更新步只在新帧到来时执行（这是关键——两个速率不同，写成"有新数据就 update，没有就只 predict"的结构）。这样即使摄像头 60 fps 而控制环 500 Hz，状态估计也是 500 Hz 平滑输出的，顺便解决了"控制环拿不到新数据只能保持旧值"造成的阶梯状抖动。

时间戳对齐。更严谨的做法是让摄像头模块在发送坐标时附带采集时刻（或 MCU 在收到帧头时打时间戳），然后把该帧的观测量回溯到对应的历史状态上做更新，再重新前推到当前时刻。实现上保留一个长度 N+5 的状态环形缓冲。做不到就退而求其次：τ 用固定值，但一定要实测（LED 闪灯 + 示波器法，见第 04 条）。

目标运动的前馈。追踪匀速目标时，光靠反馈一定有滞后误差 ess = vtarget/Kv（Kv 是速度误差常数）。把估出来的目标速度直接前馈成云台角速度指令 ωff = v̂target/L（L 是距离），滞后误差立刻降一个数量级。这就是视觉伺服里"反馈保精度、前馈保跟随"的分工。

常见坑

（1）N 取过大导致过补偿：τ 估大了会让预测点冲到目标前面，系统开始"超前振荡"。从 N = round(0.7τ/Ts) 开始，逐步加到刚好不振荡。（2）用等速模型去预测正在加速的球（比如刚给完杆角）会系统性偏差，必要时升到等加速模型（三状态），但过程噪声要相应加大。（3）目标短暂丢失时卡尔曼只 predict 不 update，几十帧后估计会飘到画面外；要设丢失计数上限（如 10 帧 ≈ 160 ms），超了就冻结输出并进入搜索状态。（4）图像坐标是"上正下负"还是相反没确认，前馈符号取反，越补越偏——上电先做开环符号验证。

日志回放、软启动与失控保护

环形缓冲离线复算斜坡限速看门狗安全状态

现场只有几分钟，能不能快速定位问题取决于你有没有数据——不是有没有灵感。

日志系统。在控制中断里把关键量写进环形缓冲，主循环里慢慢往外吐。记什么：时间戳、给定 r、测量 y、估计 x̂、误差 e、各项 P/I/D 的贡献、限幅前的 uraw 和限幅后的 usat、饱和标志、状态机状态。分别记 uraw 和 usat 是最有价值的一条——看到两者长时间不等，就知道问题是执行器不够而不是参数不对，能省掉半天试参数。带宽估算：12 个 float × 4 B × 1 kHz = 48 kB/s，串口 921600 bps 刚好够（约 92 kB/s），再多就上 SD 卡或只记 200 Hz 的降采样版本。二进制格式（不要 printf 浮点，太慢），PC 端用 Python 解析。

离线回放调参。有了日志，就可以在 PC 上把控制律重跑一遍：拿记录的 y 序列喂给不同参数的 PID，看 u 会怎么变；或者拿记录的 (u, y) 对做系统辨识，直接拟合出传递函数再用 python-control 设计。这一步能把"实物试一次要 3 分钟"变成"电脑跑一次 0.1 秒"，是拉开差距的关键工具。注意回放不能替代实测（缺少闭环耦合），但足以排除掉 90% 的错误参数。

限幅与软启动。三层限幅缺一不可：给定限幅（位置指令不能超出机械行程）、给定斜率限幅（每周期最多变化 Δmax，把阶跃变成斜坡，从源头避免饱和与冲击）、输出限幅（配抗饱和，第 03 条）。软启动的典型写法是把增益本身做斜坡：k_ramp = min(1.0f, k_ramp + Ts/T_soft); Tsoft 取 0.3–1 s，输出乘上 kramp。磁悬浮还有个专门的起浮流程：先开环给一个略小于平衡值的预励磁电流（让小球被吸到线性区内），检测到位置传感器进入有效量程后再切到闭环，切换时把积分器预置为当前开环电流值以避免跳变（bumpless transfer）。

失控保护清单。每一条都要有明确的检测量和动作：

  • 位置超限：|y| > ylimit 持续 > 20 ms → 输出置零 + 报警。
  • 电流/温度超限：硬件比较器优先，软件做二次确认与记录。
  • 传感器失效：读数卡死不变（连续 N 拍完全相同）、超出物理量程、视觉连续丢帧 > 10 帧 → 进入安全状态。
  • 通信超时：上位机/摄像头 > 100 ms 无新数据 → 保持最后有效指令 200 ms，之后减速停车。
  • 独立看门狗（IWDG）：控制中断里喂狗，主循环卡死就复位；复位后不能自动重新使能功率输出，必须等待人工/按键确认。
  • 安全状态定义：小车 = 刹车 + 输出置零；云台 = 保持当前位置、激光关闭；磁悬浮 = 电流置零让球落下（比继续乱给电流安全）。
电赛怎么考

2024 赛区赛/省联赛 F 题「磁悬浮实验装置」：起浮的开环预励磁 → 闭环切换（含无扰切换）几乎是这道题的必答题，直接切闭环的方案在小球还在量程外时电流环会一路顶到限幅，然后"砰"地吸死在铁芯上；同时线圈长时间满电流会过热，温度保护不做会烧线圈。2023 国赛 I 题「气垫悬浮车」：气垫车没有摩擦力兜底，一旦控制失效就是直接撞出赛道，失控保护（超限检测 + 停机）与软启动是保住器材和成绩的底线。

常见坑

（1）在控制中断里 printf：一次浮点格式化几百微秒，直接把 1 kHz 中断打爆，表现为"加了日志系统就不稳了"。中断里只做定长二进制拷贝。（2）日志没有时间戳或时间戳用主循环计数，回放时时间轴对不上，微分算错。用硬件定时器计数当时间戳。（3）保护阈值设得太紧，正常超调就触发停机，队员干脆把保护注释掉——阈值应设在物理极限的 80%，而不是性能指标附近。（4）看门狗复位后自动恢复输出，形成"复位—发疯—复位"的循环，比不加看门狗更危险。（5）软启动只做了上电那一次，中途换模式（如从定点切到循迹）时给定跳变照样冲击；每次模式切换都要走无扰切换流程。

前馈解耦与三类典型失分

扰动前馈a/g 解耦稳态误差极限环失分排查

"小车一走球就掉"不是 PID 没调好，是你在用反馈去追一个本来可以提前算出来的扰动。反馈天生滞后：扰动要先造成误差，控制器才动作。而小车的加速度是你自己发出去的指令，完全已知——这就是前馈能起作用的全部理由。

车载滚球的前馈解耦公式。在随小车平动的非惯性系里，球受到惯性力 −m·acar，把它并进第 01 条的方程：

(7/5)·ẍrel = g·θ − acar
令 θff = acar / g   ⇒   惯性力项被完全抵消，球在车上等效于静止台面
xrel 球相对杆的位置，acar 小车沿杆方向的加速度，θff 需要额外倾斜的杆角（弧度）

算一组数：acar = 1.0 m/s2 → θff = 0.102 rad = 5.85°。这是个很大的角——如果不前馈，反馈要等球滚偏了才开始纠正，1 cm 的误差预算瞬间用光。转弯时同理，横向的向心加速度 an = v2/R：v = 0.5 m/s、R = 0.5 m 时 an = 0.5 m/s2 → 横向杆角前馈 2.9°。

代码级实现要点（伪码，控制中断里）：

  • 用规划的加速度，不用实测的：a_ff = traj.a_cmd[k]; 小车的梯形/S 形速度规划本来就产出 a(t)，它无噪声、且可以提前取（取 k + Nlead 拍，Nlead 补掉舵机的 30–80 ms 滞后），这是实测加速度做不到的。
  • 坐标投影：前馈量要投到杆的方向上，a_par = a_ff*cos(psi); a_perp = a_ff*sin(psi);（ψ 是杆轴与小车前进方向夹角）。单轴球杆只取平行分量。
  • 合成与限幅：theta_cmd = pid_ball(x_ref - x_hat, ...) + a_par/G + Kv*v_ref/G; 再统一做角度限幅与斜率限幅。前馈项不进积分器。
  • 加一个前馈增益系数 k_ff（0.7–1.0），实测时从 0 开始往上加，看球在小车启动瞬间的偏移量最小时取谁——理论值 1.0 通常略微过补偿，因为杆角还有滞后。
  • 把 IMU 测到的车身俯仰角一并补掉（上坡时重力分量等效于恒定 a），theta_cmd -= pitch_body;

失分类型二：稳态误差消不掉。排查顺序固定：① 先确认是不是执行器饱和（看日志里 uraw vs usat，见第 11 条）——饱和时加 I 没用；② 再确认是不是死区/静摩擦（误差小于某个值就完全不动 → 加库仑摩擦前馈，第 08 条）；③ 再确认是不是传感器零位偏了（把目标设成当前实测值，看系统是否稳定，能稳定说明闭环没问题、是标定问题）；④ 最后才是加积分，且必须配抗饱和 + 积分分离（|e| 大时不积分，|e| < eth 才开积分，eth 取指标的 2–3 倍）。顺序反了就会陷入"加 I → 超调 → 减 I → 有静差"的死循环。

失分类型三：来回震荡不收敛。先分清三种振荡，处理方法完全不同：

判据很简单：把示波器/日志的振荡周期量出来，换算成频率再对号入座，比盲目减小 Kp 高效得多。

电赛怎么考

2026 赛区赛/省联赛 H 题「车载平衡滚球运动控制系统」：这是本条的正面战场——整圈 ≤ 30 s 逼着小车加减速和转弯，而钢球误差 ≤ 1 cm 又不允许球被甩偏。只靠加大 PID 增益的队伍会在小车启停瞬间丢球或者超差；把 θff = acar/g 前馈到摆杆角指令上，同一套反馈参数就能同时满足两条指标，这一条前馈的性价比高过任何参数微调。2025 国赛 E 题「简易自行瞄准装置」：小车行进中瞄准，车体运动同样是已知扰动——把小车位姿变化前馈到云台角度指令（几何解析），而不是等图像误差出现再闭环，是瞄准时间和精度两项指标同时达标的前提。2023 国赛 E 题「运动目标控制与自动追踪系统」：目标匀速运动时的滞后误差属于典型的"稳态误差消不掉"，正解是速度前馈而不是猛加积分。

常见坑

（1）用加速度计实测 acar 做前馈：加速度计噪声大、还混着车身振动和重力分量，前馈进去等于往指令里灌噪声。优先用轨迹规划器输出的 acmd，实在要实测就对轮速编码器做差分 + 低通（截止 5 Hz）。（2）前馈项误接进积分器，导致小车匀速时积分继续累积。前馈必须加在 PID 输出之后。（3）前馈符号搞反：静态验证法——把小车放在斜坡上（等效恒定加速度），看前馈项是否让杆往正确方向倾。（4）前馈调好后忘了重新整定反馈：前馈把扰动幅度降下来后，原来为了抗扰而调大的 Kp 现在偏大了，会引入不必要的超调，应该回过头把 Kp 适当降下来。

参考设计方案

按题型给出可直接落地的技术路线，含拓扑与算法选型。

  • 车载平衡滚球（2026 H）：典型 ball-and-beam 串级控制。外环用摄像头测球位（题目强制），内环控摆杆角度（舵机 / 电机 + 编码器）。核心难点是小车行驶带来的加速度扰动——把小车的目标加速度作为前馈量直接补到摆杆角度指令上，比单纯加大 PID 增益有效得多。视觉延迟用等速卡尔曼预测补偿。
  • 磁悬浮（2024 F）：本质不稳定系统，必须先线性化再设计。位置检测用光电对管或电感式；电流内环 + 位置外环，位置环需要超前校正提供相位裕度。起浮瞬间用开环预励磁再切闭环。
  • 自行瞄准（2025 E）：小车循迹（题目强制 MSPM0）+ 二维云台激光瞄准。云台标定是关键：建立"小车位姿 → 靶面坐标 → 云台两轴角度"的映射，用几何解析而非纯图像闭环，速度更快。
  • 运动目标追踪（2023 E）：视觉伺服。图像坐标误差直接作为云台角速度指令（IBVS），加入速度前馈跟上匀速目标。
  • 电磁曲射炮（2019 H/J）：电容储能 + 可控硅 / IGBT 放电驱动线圈，射程靠充电电压与触发时序标定；本质是开环标定 + 查表，而非闭环控制。
